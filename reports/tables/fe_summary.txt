4. Text: 100,000 TF-IDF terms; chi² selection did not improve validation F1-macro, all terms are kept.
5. Feature groups: best combination on validation = text + tabular + game (F1-macro 0.8242); text-free combination: 0.6360.
6. PCA on tabular features: not used; TruncatedSVD on text: not used (decided by validation F1-macro).
7. Final pipeline: 100,293 features, probe validation F1-macro 0.8242, PR-AUC (negative) 0.8045. The test set was not used.
